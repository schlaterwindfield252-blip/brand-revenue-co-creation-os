# 品牌营收共创系统

一套面向一人公司、独立创业者和小团队的 Codex Skill，用客户证据连接品牌承诺、营销触达、报价成交和交付结果。

它帮助你回答：根据现在掌握的事实，下一步最值得做什么，投入多少，以及看到什么结果后继续、调整或停止。

> 当前版本：`v0.1.0-beta`。这是工作框架，不承诺营收增长；真实经营效果仍需通过项目记录验证。

## 适合解决的问题

- 客户问完价没有下文，应该先改报价、换客群还是补充证明？
- 内容有曝光却没有合格咨询，问题在客群、信息、渠道还是承接？
- 订单增加后交付失控，如何同时处理范围、回款和产能？
- 品牌承诺、销售说法和实际体验不一致，应该先修哪里？
- 新业务缺少证据，怎样设计一项成本可控、能够推翻假设的测试？

## 服务对象

- 一人公司与独立创业者
- 自由职业者、顾问和专业服务者
- 创始人主导的小团队
- 需要连接品牌、营销、销售与交付的业务负责人

## 安装

1. 从 Releases 下载 `brand-revenue-co-creation-os-v0.1.0-beta.zip`。
2. 解压后确认目录名为 `brand-revenue-co-creation-os`。
3. 将整个目录复制到 Codex 的 skills 目录。
4. 在新对话中使用 `$brand-revenue-co-creation-os` 调用。

不同环境的 Skill 安装方式可能不同；本仓库不声称已经覆盖所有客户端。

## 第一次使用

复制下面的提示，填入你已经知道的信息：

```text
使用 $brand-revenue-co-creation-os 帮我判断下一步。

我做的业务是：
我现在要决定：
最近真实发生的是：
我最多能投入的时间和钱是：

请指出当前判断和依据、最关键的未知、一个下一动作，以及看到什么结果后继续或停止。信息不足的地方保持未知。
```

默认输出集中在四件事：当前判断与依据、关键未知、下一动作、继续或停止的复核条件。

## 使用深度

- 轻量决策：处理一个具体问题、判断或产物。
- 项目推进：跨品牌、营销、销售或交付阶段持续实施。
- 效果评估：复盘真实试点，区分模拟演练与经营结果。

## 目录

- `SKILL.md`：入口、路由和共同规则
- `references/integrated/`：证据、阶段门、门槛和输出规则
- `references/brand-system.md`：公开发行版的品牌决策模块
- `references/marketing/`：客群、信息、GTM、渠道、内容和实验
- `references/revenue/`：客户验证、报价、销售、交付和指标
- `references/extensions/`：现金、产能、履约、合规和行业适配
- `assets/`：按需复制的行动卡、记录表和项目模板

## 使用边界

- 不虚构客户、预算、成本、愿付价格、市场数据或经营结果。
- 付款可以证明一次购买承诺，不能单独证明交付价值或可复制增长。
- AI 可以分析、整理、计算和起草；实际访谈、承诺与经营执行由使用者负责。
- 法律、税务、会计和受监管事项需要适当的专业支持。
