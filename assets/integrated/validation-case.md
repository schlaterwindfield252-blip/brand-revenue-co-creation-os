# Skill真实项目验证记录

这是待填写的记录模板，不是效果证据。用户未提供实际记录时保持空白或写未知；不得补成虚构成功案例。合成材料需在标题及结果处明确标注。

## 来源与范围

- 案例ID / 记录日期：
- 真实项目或合成演练：
- Skill版本/文件快照 / 使用模型与环境（可获得时）：
- 业务类型、报价/客群、所处阶段：
- 真实原始材料、输出、结果证据的位置（可匿名）：
- 记录人 / 评估人 / 客户材料可用范围：

## 执行前登记

- 本次决定与已存在的直接证据：
- 基线：原始数量、分子/分母、时间窗、缺失：
- 原本准备采取的行动（未发生的反事实须标假设）：
- Skill建议及实际改变的决定：
- 用户采纳了哪些；未采纳的原因：
- 成功/失败/证据不足及各自对应的下一决定：
- 成本、工时、容量上限与停止条件：
- 反指标 / 可能的外部影响：
- 负责人、结果窗口与复核点：

## 执行后追加

- 已执行 / 未执行 / 部分执行，实际动作及偏离：
- 实际现金、工时、数据整理与维护成本：
- 观察到的行为及经营结果、证据位置：
- 失败、无变化、反例、缺失和意外后果：
- 客户反馈与确认范围：
- 同期其他变化与竞争解释：
- 用户是否愿意继续使用、哪些负担应删除：
- 结论：结构可用 / 行为可用 / 本项目观察到结果 / 无改善 / 证据不足（说明依据）：
- 因果解释的限度、可适用和不可推广范围：
- 下一决定、复核点及必要的Skill修订：
