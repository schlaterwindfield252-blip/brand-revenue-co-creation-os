# 决策与行动卡

用于需要持续跟进的一项决定。可写入已有记录；不用的栏目可删，未确认值标“建议”或“待定”。

- 记录ID / 日期 / 业务及报价范围：
- 这次要决定什么：
- 当前判断、依据及证据位置：
- 最关键的未知 / 反证 / 其他解释：
- 下一动作及它能区分的假设：
- 现金 / 时间 / 容量上限及依据：
- 成功后允许做什么：
- 什么结果会改变判断或停止：
- 哪些情况属于证据不足：
- 负责人 / 日期或复核事件（标明是否已确认）：

复核时追加：
- 实际执行、投入及偏离：
- 观察结果、样本/时间窗和证据位置：
- 状态：通过 / 未通过 / 证据不足 / 限额试行 / 不适用
- 新决定、理由与下一复核点：
