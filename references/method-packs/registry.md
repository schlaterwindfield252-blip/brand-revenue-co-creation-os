# 方法登记表

每个方法登记：

| 字段 | 内容 |
|---|---|
| method_id | 稳定ID |
| method_name | 方法名称 |
| source | 来源及可追溯位置 |
| version_date | 版本与日期 |
| license_boundary | 许可/版权边界 |
| status | experimental/project-only/approved-extension/retired |
| decision | 它帮助改变的决定 |
| applicable_stage | 生命周期阶段 |
| applicable_context | 客群、行业、规模和前提 |
| required_inputs | 必要输入 |
| expected_outputs | 可验收输出 |
| evidence_level | 当前证据强度 |
| known_limits | 不适用、失败或偏差 |
| conflicts | 与核心或其他方法的冲突 |
| risk | 数据、合规、品牌和经营风险 |
| owner | 维护者 |
| review_date | 复核日 |
| promotion_criteria | 晋升标准 |

登记不是认可。未通过项目验证的方法必须在输出中清楚标记实验性质。
