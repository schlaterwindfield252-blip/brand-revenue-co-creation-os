# 营销激活路由

营销激活负责把品牌价值和报价带到合适对象面前，并把行动证据交给营收系统。探索期可以测试明确标注的价值与报价假设；扩大投入需要相应的购买、交付与经济证据。

| 问题 | 读取 |
|---|---|
| 不知道市场发生了什么、竞品和替代是谁 | [市场情报](market-intelligence.md) |
| 客群太宽、资源无法集中 | [客群与 ICP](segmentation-and-icp.md) |
| 用户看见但听不懂、记不住或不行动 | [定位与信息](positioning-and-messaging.md) |
| 新产品/服务如何进入市场 | [GTM](go-to-market.md) |
| 渠道太多或不知道先做哪个 | [渠道组合](channel-portfolio.md) |
| 内容多但不产生有效行动 | [内容系统](content-system.md) |
| 要策划一次活动或Campaign | [活动运营](campaign-operations.md) |
| 首购后没有激活、复购或推荐 | [生命周期营销](lifecycle-marketing.md) |
| 想快速测试增长假设 | [增长实验](growth-experiments.md) |
| 指标多但无法判断有效性 | [衡量与归因](measurement-attribution.md) |
| 工具、数据和权限混乱 | [营销技术与数据治理](martech-data-governance.md) |

营销实验可以帮助验证价值，持续扩量不能掩盖已知的产品或交付失败。先区分未知、失败与限额试行，见 [阶段门](../integrated/lifecycle-gates.md)。若流量增加后交付或现金更差，先处理产品、报价、容量或服务约束。
