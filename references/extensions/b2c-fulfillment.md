# B2C商品履约与客诉闭环

## 优先级规则

客户伤害、产品/食品安全、监管风险或同批次广泛承诺违约，优先级高于转化、Campaign和销售目标。立即停止相关扩量，隔离批次/库存、保存证据、主动保护受影响客户，并转交适用专业流程。

## 订单履约链

承诺版本 → 可售库存 → 下单与支付 → 拣选 → 质检 → 包装 → 发运 → 物流状态 → 签收 → 使用/激活 → 退换/退款 → 价值与复购。

每单关联客户、SKU、批次、承诺版本、渠道、仓/供应方、物流、异常和处理结果。

## 核心控制

### 承诺与库存

- 商品页、活动、客服和订单中的规格、时效、赠品、退换和限制一致；
- 区分在库、可售、锁定、在途、损坏和安全库存；
- 缺货、超卖或供应变化有停止销售、替代、延期或退款规则。

### 拣选、包装与发运

- 拣货、复核、批次/序列、数量、质量和地址有检查点；
- 包装按产品风险和运输线路测试；
- 发运窗口、承运人交接和超时预警有责任人。

### 收货、退换与退款

- 客户能理解如何验收、保存、使用和举证；
- 区分错发、少发、破损、变质/失效、延误、描述不符、使用问题和主观不适配；
- 处理规则保护客户权益，同时把成本和原因回写产品、供应、包装、物流或承诺。

## 客诉严重度

- S1：安全、监管、群体性或重大承诺违约——立即停批/停售、升级决策者和专业方；
- S2：影响使用或价值的明确错误——优先补救并定位系统原因；
- S3：一般咨询、偏好或可指导问题——按SOP处理并观察是否重复。

## 分析

按批次、SKU、渠道、供应方、线路、包装版本、客户首购/复购和时间队列分析，不只看总客诉率。同步看退款、补发、处理时长、贡献毛利、复购和品牌影响。

## 扩量门槛

可售库存可信、承诺准确、履约SLA有实际证据、主要异常可定位、补救成本可承受、容量有缓冲、没有未关闭S1风险。否则先修复履约，不加投放。
