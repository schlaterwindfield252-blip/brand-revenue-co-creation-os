# 证据模型

## 分开保存观察与解释

| 类型 | 记录要点 |
|---|---|
| 事实或事件 | 来源、日期、适用客群与范围 |
| 客户原话 | 原话、匿名ID、角色、情境、日期；不得把转述加引号冒充原话 |
| 行为 | 搜索、替代、采购、付款、使用、验收、复购等事件、时间和结果 |
| 推断 | 解释、依据、竞争解释、信心及其理由 |
| 假设 | 可被推翻的命题、反证标准、下一测试 |
| 争议与决定 | 各方证据、决定者、理由、反对证据、复核点 |
| 实验 | 版本、对象、成本、样本/窗口、门槛、执行偏差与结果 |

轻量任务只记录本次决定所需字段；持续项目使用稳定ID串联原材料与行动。重复引用同一访谈或同一客户不增加独立样本数。

## 按命题判断强弱，不用一条总排名

| 要判断的命题 | 更直接的证据 | 单独不足以证明 |
|---|---|---|
| 问题存在及其情境 | 具体经历、替代行动、实际代价 | 抽象认同、功能喜好 |
| 有购买承诺 | 真实付款、不可忽略的采购投入；注明是否可撤销或关联交易 | 点赞、“我会买”、无约束意向 |
| 能交付所承诺价值 | 实际使用、验收、对应结果、投诉与反例 | 付款、发出交付物 |
| 有长期或可重复价值 | 适配业务周期的客户结果、留存/复购、独立对象或周期的复现 | 单一大客户、一次推荐、短期促销 |
| 某项动作造成结果变化 | 可比较基线/对照、时序、执行记录与替代解释检查 | 单次前后变化、行业平均数 |

同一笔付款可能来自关系、折扣或试验预算；它是付款事实，不自动证明价值、盈利或代表性。预算与采购进展可以是长周期B2B的有效中间证据，但仍需区分已成交与未成交。

## 检查四个限制

- **相关性**：证据是否支持当前命题，而非邻近命题？
- **代表性**：来自谁、谁没被观察、是否仅是熟人或高意愿客户？
- **独立性**：多少独立客户/账户/周期，是否重复计数？
- **时效与完整性**：报价、客群、渠道是否已变，是否存在缺失、退款或尚未完成的周期？

信心用文字解释依据和限制，不给无校准基础的精确概率。口径冲突时并列保留，先核查影响决定的差异。

## 禁止替代与下一测试

礼貌反馈不替代购买，交付不替代验收，沉默不替代满意，行业均值不替代企业成本。AI模拟只能帮助设计问题或检查逻辑，不能进入真实客户样本。

选择有现实可能推翻假设的最小测试：访谈用于情境，概念测试用于理解，付款用于承诺，试点用于交付，适配周期的回访用于价值。成功/失败/不确定按 [门槛校准](decision-calibration.md) 预先区分。

完整账本可包括：稳定ID、日期、来源、客群、场景、角色、原话/行为、命题、解释、信心理由、反证、下一测试及授权状态；无需为一次性分析新建全部字段。
