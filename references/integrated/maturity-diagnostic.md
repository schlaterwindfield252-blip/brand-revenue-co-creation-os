# 品牌营收成熟度诊断

只用于问题不清楚或用户要求系统检查时；已知具体决定就直接处理。它是讨论证据覆盖的工具，未经校准的分数不预测增长、不证明因果、不用于企业排名。

## 先判适用，再描述证据

默认描述“未知/假设/有限直接证据/多次证据/跨周期复现”。只有用户需要评分或持续对比同一业务时才用0–4：
- 0：尚无可核查记录；不代表能力不存在。
- 1：有明确假设，尚无相关直接证据。
- 2：有相关直接证据，数量、代表性或时间窗仍有限。
- 3：在可比范围有多次相关证据，记录独立对象与反例。
- 4：在完整且可比的多个周期中复现，适用边界清楚。

使用 `unknown` 或 `not-applicable` 单独记录未知/不适用，不硬塞进分数。一笔付款可以直接证明一次购买，但不能自动让整个维度升到3分。

| 维度 | 检查问题 |
|---|---|
| 客户证据 | 场景、经历、替代、代价和行为是否可核查？ |
| 利益相关者 | 当前决定涉及的参与者、利益与决策权是否清楚？ |
| 品牌价值 | 承诺是否具体且由体验支持，差异是否有证据？ |
| 产品与报价 | 买家、结果、范围、价格、成本和证明是否足够支持下一动作？ |
| 市场触达 | 能否接触目标客户，渠道证据支持多大范围？ |
| 信息与内容 | 信息是否被理解并引向适当动作？ |
| 销售 | 采购进展、胜负原因及下一步是否可核查？ |
| 交付 | 首个价值、验收、异常和付款是否受控？ |
| 经济 | 贡献、回款、现金和容量的口径与未知是否清楚？ |
| 后续价值 | 复购/续约/推荐是否适用，观察周期是否到达？ |
| 协作与知识 | 关键事实与决定是否可找回，有无重复录入？ |
| 风险治理 | 当前适用的风险、授权与专业依赖是否处理？ |

只评与问题相关的维度；不计算总分。用 [评分底稿](../../assets/integrated/maturity-scorecard.csv) 时在 `evidence` 字段写入证据位置、对象与时间窗，在 `confidence` 字段说明限制；`score_0_to_4` 可留空，并在证据栏说明未知/不适用。

## 如何校准并选动作

同一维度比较前，固定命题、业务范围、时间窗和锚点示例；不同评估者出现分歧时先核对原始证据，不平均分数掩盖分歧。业务类型不同，不横向排名。

按当前损失、紧迫性、证据和回退代价选优先动作；前序低分只是候选解释。多个约束共同阻断行动时注明依赖关系，结束时给出下一动作和复核点，不强求唯一根因。
