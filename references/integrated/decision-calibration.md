# 门槛校准：什么证据足以支持本次动作

在设成功、失败或扩量门槛时读取。先确定要作的决定，再确定证据要求；不从通用转化率、统一访谈人数或成熟度总分推导业务结论。

## 1. 写清命题和决策范围

用“在什么客群、情境、报价版本和时间窗内，观察到什么，足以支持哪一步”描述门槛。问题存在、愿意购买、交付有效、渠道可重复是不同命题，分开判断。

证据可支持一个限额试点，但不一定支持扩大投放。用户批准预算也不等于市场已验证。

## 2. 根据错误代价选择证据要求

| 行动 | 证据要求与可执行范围 |
|---|---|
| 内部草案、访谈提纲、可撤回原型 | 标注假设即可推进；不要求先有付费客户 |
| 有限成本的客户实验 | 指定对象、信息/报价版本、实际行为、成本与期限上限；承诺可兑现 |
| 招聘、备货、长期合同、持续扩量 | 本业务的获客、交付、回款、现金和容量证据；检查不利情境和退出代价 |
| 涉及实际伤害、产品安全或受监管事项 | 用相关专业要求和风险处置约束行动，不能用增长收益抵消 |

## 3. 建立本地门槛

在运行前记录：
- **指标与来源**：分子、分母、纳入/排除条件、时间窗、采集方式和证据位置。
- **商业可承受性**：按实际成本、回款安排和可用工时推导上限；成本口径、创始人时间与固定开支分别说明，防止漏算或重复计算。
- **成功与失败**：观察到什么分别支持继续或推翻哪条假设。
- **停止与不确定**：预算耗尽、承诺无法兑现等可独立触发停止；样本不足、周期未到、数据缺失或执行偏离计划属于不确定。
- **复核**：已知负责人、日期或业务事件；区分用户已定与模型建议。

按数据基础选择：
- 有历史数据：比较相似客群、完整周期和一致口径，同时记录季节、渠道与报价变化。
- 无历史数据：先设学习目标、时间/成本上限与可观察行为，再运行限额试点；不把假设阈值写成行业基准。
- 样本很小：报告原始数量、分布和反例，不用精确概率、显著性或“已跑通”掩盖不确定性。
- 长销售/复购周期：把可核查的预算、采购推进、试用采用等列为中间证据；不等同付款或长期价值。

## 4. 决定如何处理未知

只对会改变下一动作的未知追加取证。取证成本高于当前可撤回行动的潜在损失时，可以说明依据后建议限额试行。不可回退或影响客户承诺的关键未知未解决时，先缩小范围或取证。

一次阴性结果需检查曝光对象是否合格、是否真正看到报价、行动入口是否正常、观察周期是否足够。不能因为零成交就断言“市场没有需求”，也不能不断调整解释使假设永远无法被否证。

实验中改变样本、报价或成功规则时保留原版本和原因，新结果单独记录；不能把事后改门槛伪装成达标。

## 校准示范（虚构，仅说明逻辑）

某咨询试点的已约定限制是假设预算500元、总投入8小时、最多交付1个试点；准备向6个已确认符合客群的对象出示同一份报价。此处数字仅属于本示例。

- 命题：至少有人愿以该范围和价格参加一次付费试点。
- 成功：出现1个真实付款且范围已确认；只支持交付该试点，不支持可复制获客或扩量。
- 失败：合格对象都完成了约定观察窗口、确实收到并理解报价，但无人购买；暂不按现方案追加投入，复核拒绝原因，不能推断整个市场无需求。
- 不确定：6个对象中只有2个收到报价，或采购流程尚未到决策点；即使零付款也不能判定价值主张失败。
- 停止：达到时间/成本上限或试点容量已满；无论成功率如何都停止本轮继续招募。
